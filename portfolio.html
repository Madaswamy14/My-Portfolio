Docs QA pipeline

Documentation Quality Automation Tool

Type: Documentation Automation | Format: Python Validation CLI

A Python checker that scans markdown docs for broken links, missing images, and invalid heading references so issues are caught before publishing.

Problem
Large documentation sets accumulate broken references quickly, and manual review does not scale well enough for release-quality docs operations.
Automation approach
Built a recursive checker that validates local markdown targets, image paths, extensionless doc links, and optional remote URLs with automation-friendly CLI output.
Outcome
Helps documentation teams catch quality issues earlier, reduce manual review effort, and improve confidence in release-ready docs.
What this proves
CI-ready documentation QA, documentation reliability thinking, and the ability to treat docs as a testable system instead of a manual review task.
