# Developer Portal Overview

This Docusaurus site is a **developer documentation portfolio** designed to show how I structure a modern documentation product for APIs, onboarding, and workflow-heavy product experiences.

## What this portal demonstrates

- documentation case studies migrated from standalone writing samples
- task-based quickstarts
- onboarding and implementation guidance
- API reference architecture
- SDK-oriented onboarding patterns
- documentation hierarchy built for real developer workflows

## Why this matters for DevEx roles

Hiring managers evaluating technical writers and DevEx writers usually want more than isolated writing samples. They want to see whether a candidate can build a **cohesive documentation system** with clear entry points, strong sequencing, and implementation-ready content.

This portal is intentionally structured like that kind of system, and the Acme Payments section extends that proof into a fuller developer-portal example with quickstart, authentication, API reference, concepts, tutorials, and production-readiness guidance.
