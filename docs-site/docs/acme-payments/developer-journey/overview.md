# Developer Journey Overview

This section maps the full lifecycle of integrating the Acme Payments API, from discovery through production readiness.

## The journey

1. **Discover the API** : Start with [Acme Payments Developer Platform](../intro.md) and the [API Reference Overview](../api-reference/overview.md).
2. **Get an API key** : Complete the [Onboarding](./onboarding.md) flow and generate sandbox credentials.
3. **Make the first API call** : Create a customer and payment in the [First Payment Journey](./first-payment.md).
4. **Handle errors** : Design for validation failures, retries, and bad credentials in the [Error Handling Journey](./error-handling.md).
5. **Implement webhooks** : Support asynchronous payment state changes in the [Webhooks Journey](./webhooks.md).
6. **Monitor usage** : Track request IDs, webhook delivery failures, and support workflows in the [Monitoring and Observability Guide](./monitoring-observability.md).
7. **Upgrade to production** : Finish the [Production Checklist](./production-checklist.md).

## Why this matters

Great developer portals do not stop at isolated reference pages. They show how a developer moves from initial exploration to a reliable production integration.
