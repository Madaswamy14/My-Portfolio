# Facebook Events Quickstart

This migrated sample shows how I turn a feature-focused help topic into a workflow tutorial with clearer preparation, decisions, and next steps.

## Documentation goal

Help organizers move from event planning to publication without guessing what information they should prepare first.

## Quickstart checklist

- confirm the event title, date, time, and format
- prepare the location or meeting link
- draft a one-sentence attendee value proposition
- choose whether the event should be public or private

## Key concepts

| Concept | Why it matters |
| --- | --- |
| Event value | Readers decide whether to attend in seconds, so the core benefit must appear early. |
| Visibility | Public and private events support very different reach and control goals. |
| Promotion cadence | Event pages perform better when reminders and updates continue after publication. |

## Core workflow

1. Create the event page with the required logistics and a clear description.
2. Preview the page before publishing so mobile and desktop details stay readable.
3. Invite the closest-fit audience first, then expand into broader promotion.
4. Post updates before the event and follow up after the event ends.

## Why this sample works as documentation

- it gives the user a quickstart entry point before the UI steps
- it separates planning concepts from execution tasks
- it ends with concrete next actions instead of stopping at publication

## Next steps

- refine titles and cover creative for faster scanning
- coordinate cross-channel promotion with email or partner posts
- measure invites, RSVPs, and follow-up engagement
