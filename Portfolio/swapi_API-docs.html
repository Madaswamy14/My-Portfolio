Star Wars API Documentation

The Star Wars API (SWAPI) provides data from the Star Wars universe, such as characters, films, and planets. This document describes how to make API calls to retrieve this data.

API Overview

The Star Wars API (SWAPI) provides comprehensive data from the Star Wars universe, including characters, films, planets, species, vehicles, and starships.

Getting Started

Base URL

https://swapi.dev/api/

Prerequisites

To make API calls, use curl or httpie. Install these tools using curl or httpie package manager.

Authentication

SWAPI is an open API and does not require authentication or authorization.

Pricing

SWAPI is free to use.

Status Codes

SWAPI uses the following response status codes:

200 OK - Request succeeded
404 Not Found - Resource not found
429 Too Many Requests - Rate limit applied
500 Internal Server Error
502 Bad Gateway
503 Service Unavailable
Rate Limits: The system blocks IP addresses that exceed specified rate limits. The rate limit for general requests from an IP address is 10,000 requests per day.

API Reference

People

Get all People

GET

Retrieves details about all the people in the Star Wars universe.

Request Endpoint

https://swapi.dev/api/people

Query Parameters

This API does not accept any query parameters.

Response Parameters

Parameter Child Parameter Data Type Description
count - integer Total number of people.
next - nullable string URL of the next page. Null if no subsequent page exists.
previous - nullable string URL of the previous page. Null if no subsequent page exists.
results - array of objects
name string Name of the person.
height string Height of the person.
mass string Mass of the person.
hair_color string Hair color of the person.
skin_color string Skin color of the person.
eye_color string Eye color of the person.
birth_year string Birth year of the person.
gender string Gender of the person.
homeworld string URL of the person's homeworld.
films array of strings URLs of films the person appeared in.
species nullable array of strings URLs for the species of the person.
vehicles nullable array of strings URLs of vehicles the person piloted.
starships nullable array of strings URLs of starships the person piloted.
created string The date and time the person's record was created.
edited string The date and time the person's record was last edited.
url string URL containing details for the person.

Get People

GET

Retrieves a specific person by their unique ID.

Request Endpoint

https://swapi.dev/api/people/{id}

Example: https://swapi.dev/api/people/5

Path Parameters

Parameter Required Data Type Description
id Yes integer Unique identifier for the person to retrieve.

Response Parameters

Parameter Data Type Description
name string Name of the person.
height string Height of the person.
mass string Mass of the person.
hair_color string Hair color of the person.
skin_color string Skin color of the person.
eye_color string Eye color of the person.
birth_year string Birth year of the person.
gender string Gender of the person.
homeworld string URL of the person's homeworld.
films array of strings URLs of films the person appeared in.
species nullable array of strings URLs for the species of the person.
vehicles nullable array of strings URLs of vehicles the person piloted.
starships nullable array of strings URLs of starships the person piloted.
created string The date and time the person's record were created.
edited string The date and time the person's record were last edited.
url string URL containing details for the person.
