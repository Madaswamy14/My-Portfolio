SWAPI API Reference

A cleaner reference for exploring Star Wars resources, request patterns, and people endpoints

Version: 2.0 Updated: March 13, 2026 Audience: Developers learning REST API request and response patterns

SWAPI is a public REST API for Star Wars data. Use this reference to make your first request, understand common request conventions, and work with the people resource using list and detail endpoints.

API Overview

SWAPI exposes Star Wars resources such as people, films, planets, species, vehicles, and starships over simple JSON endpoints. It is useful for learning REST fundamentals because requests are read-only, no authentication is required, and responses follow consistent collection and resource patterns.

Base URL

https://swapi.dev/api/

Authentication

No authentication or API key is required for standard read requests.

Response format

Responses are returned as JSON objects. Collection endpoints include pagination fields such as count, next, previous, and results.

Quickstart

Use the quickstart below to confirm you can call the API and inspect a successful response.

Prerequisites

  • A terminal, browser, or API client such as curl, PowerShell, Postman, or Insomnia
  • Internet access

Make your first request

  1. Open a terminal or API client.
  2. Send a GET request to https://swapi.dev/api/people/1/.
  3. Confirm that the response status is 200 OK.
  4. Review the JSON body for fields such as name, height, films, and homeworld.
Result: You have successfully made a basic SWAPI request and retrieved a single resource.

Key Concepts and Conventions

Use these conventions to understand the examples, troubleshoot responses faster, and move from quickstart requests into full endpoint reference work.

HTTP method

This reference uses GET requests because SWAPI is typically used as a read-only public API.

Query parameters

Collection endpoints may support query parameters such as page for pagination and search for filtered results.

Resource paths

Individual resources are addressed by ID, for example /people/5/. Linked resources in the response are returned as URLs.

Common status codes

200 OK - Request succeeded
404 Not Found - Resource does not exist
5xx Server Error - Temporary service problem
Tip: If you are documenting or testing the API, use the canonical https://swapi.dev/api/ URL format consistently in examples and screenshots.

API Reference

People

The people resource returns character records from the Star Wars universe.

List People

GET

Returns a paginated list of people records.

Request Endpoint

https://swapi.dev/api/people/

Query Parameters

Parameter Required Data Type Description
page No integer Returns a specific results page.
search No string Filters people records by a search term, such as a character name.

Response Parameters

Parameter Child Parameter Data Type Description
count - integer Total number of matching people records.
next - nullable string URL for the next results page, or null if no later page exists.
previous - nullable string URL for the previous results page, or null on the first page.
results - array of objects Array of people resources returned for the current page.
name string Name of the person.
height string Height of the person.
mass string Mass of the person.
hair_color string Hair color of the person.
skin_color string Skin color of the person.
eye_color string Eye color of the person.
birth_year string Birth year of the person.
gender string Gender of the person.
homeworld string URL of the person's homeworld resource.
films array of strings URLs of films in which the person appears.
species array of strings URLs for the species linked to the person.
vehicles array of strings URLs of vehicles the person piloted.
starships array of strings URLs of starships the person piloted.
created string Date and time the resource was created.
edited string Date and time the resource was last updated.
url string Canonical URL of the person resource.

Get a Person

GET

Returns a single person resource identified by ID.

Request Endpoint

https://swapi.dev/api/people/{id}/

Example: https://swapi.dev/api/people/5/

Next Steps and Troubleshooting

If a request fails, start by checking the URL path, resource ID, and trailing slash. Then expand into additional resources once the basic people endpoints are working.

Troubleshoot 404 responses

Verify that the endpoint path and resource ID exist and that you are using the canonical swapi.dev URL format.

Test pagination and search

Call /people/?page=2 and /people/?search=luke to verify query parameter behavior.

Expand to more resources

After people endpoints are clear, document films, planets, starships, and linked resource relationships the same way.
