Star Wars API

Retrieve metadata from Star Wars universe or control your application's data access

Star Wars API enables the creation of applications that can interact with Star Wars universe data, such as retrieving character metadata, accessing film information, or exploring planets and species.

Getting started

This is where the magic begins! The following steps will help you to get started with your journey towards creating some awesome Star Wars apps using the API:

  1. No registration required - SWAPI is completely open and free to use.
  2. Make your first request - Simply send HTTP requests to our endpoints. All API requests should be made to the base URL with the appropriate endpoint path.
  3. Parse the JSON response - All responses are returned in JSON format for easy integration with your applications.

You can follow the Quick Start guide to learn how to make your first SWAPI call.

Concepts

Understanding key concepts will help you make the most of the Star Wars API:

  • Base URL: All requests are made to https://swapi.dev/api/
  • Resources: People, Films, Planets, Species, Vehicles, and Starships
  • Pagination: Large result sets are paginated for better performance
  • Search: Most resources support search functionality
  • Relationships: Resources link to related entities via URLs

Reference

The Star Wars API provides comprehensive data across six main resource types:

People

Characters from the Star Wars universe including their physical characteristics, homeworld, and appearances.

GET /people/ - List all people
GET /people/1/ - Get Luke Skywalker

Films

Star Wars films including episode details, release dates, and character appearances.

GET /films/ - List all films
GET /films/1/ - Get A New Hope

Planets

Planets and locations from the Star Wars universe with climate, terrain, and population data.

GET /planets/ - List all planets
GET /planets/1/ - Get Tatooine

Species

Different species in the Star Wars universe including physical characteristics and homeworlds.

GET /species/ - List all species
GET /species/1/ - Get Human

Vehicles

Vehicles used for transportation including speeders, walkers, and other ground vehicles.

GET /vehicles/ - List all vehicles
GET /vehicles/4/ - Get Sand Crawler

Starships

Starships and space vessels including technical specifications and pilot information.

GET /starships/ - List all starships
GET /starships/9/ - Get Death Star

Examples

We've provided step-by-step examples that will guide you through making your first SWAPI calls and integrating Star Wars data into your applications.

Quick Start

Make your first request to get Luke Skywalker's data:

GET https://swapi.dev/api/people/1/

Search Characters

Search for characters by name:

GET https://swapi.dev/api/people/?search=luke

Get Film Data

Retrieve information about Star Wars films:

GET https://swapi.dev/api/films/1/
